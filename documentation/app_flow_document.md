# AI Schedule Auditor App Flow Document

## Onboarding and Sign-In/Sign-Up

When a brand-new user arrives, they land on the public homepage at “/.” This page briefly explains the AI assistant’s ability to help manage daily schedules and offers clear buttons to either sign up or sign in. To create an account, the user clicks Sign Up and chooses between entering their email and a password or using a social login provider such as Google. After submitting the registration form, the system sends a confirmation email. Once the email is verified, the user is automatically signed in and directed to their dashboard. Returning users select Sign In, fill in their credentials or pick the social login option, and are taken to the dashboard when authentication succeeds. If a user forgets their password, they click the “Forgot Password” link on the sign-in page, submit their email address, and receive a reset link. Following the link, they set a new password before being redirected back to sign in. At any point after logging in, the user can sign out by opening the profile menu in the top navigation bar and choosing Log Out, which returns them to the public homepage.

## Main Dashboard or Home Page

Immediately after signing in, the user arrives at the main dashboard located at “/dashboard.” A persistent header along the top displays the app logo on the left, a link to the chat interface, a link back to the dashboard, and a profile avatar on the right. Below the header, the page splits into two areas: the primary calendar view takes up most of the space, showing the user’s events in a weekly or daily layout, and a sidebar or lower section displays summary metric cards. The calendar is interactive and styled with shadcn/ui components, while the metrics include meeting density, focus blocks, and available free time. From this dashboard, the user can click the Chat link in the header to open the conversational AI interface or open the profile menu to navigate to settings.

## Detailed Feature Flows and Page Transitions

When the user clicks Chat in the header, the app transitions to “/chat,” which loads a client-side interface built with assistant-ui and the `@ai-sdk/react` hooks. The chat page displays the conversation history on the left and a text input at the bottom. As the user types a message describing events—such as “Tomorrow I have a meeting at 9am and gym at 5pm”—they press Send. The interface opens a streaming connection to `/api/chat`, where the backend uses the Vercel AI SDK to interpret the message, extract event details, and optionally call a function to save these events into the PostgreSQL database via Drizzle ORM. The AI’s response streams back to the chat UI, confirming the saved events or offering a quick insight. Once the conversation concludes, the user can click View Dashboard to see the newly added items on the calendar.

On the dashboard page, the calendar fetches events for the authenticated user in a server-rendered component. Clicking any event opens a detail modal, allowing the user to edit the title, start time, end time, or type. Saving changes sends a PATCH request to `/api/events/:id`, updates the database, and refreshes the calendar display. The user can also drag and drop events within the calendar grid to adjust times, triggering the same update flow behind the scenes. Below the calendar, the metrics section loads aggregated data from `/api/insights` and displays it in styled cards. Each card can expand into a modal or side panel for more detailed charts and recommendations.

In advanced workflows, an administrator view is available at “/admin.” Admin users navigate here from a link in the profile menu. The admin interface allows them to see all registered users, review chat logs, and manage configuration settings for the AI model. Navigating back to the main dashboard is as simple as clicking the Dashboard link in the admin header.

## Settings and Account Management

Accessing the profile avatar in the top header reveals a Settings option. Clicking Settings brings the user to “/settings,” where they manage their personal information, including name, email address, and password. A separate section within settings allows the user to toggle dark mode, choose default calendar views (daily or weekly), and configure notification preferences for email reminders or push notifications. If the application offers a paid tier, a Billing tab appears under Settings, guiding the user through upgrading their subscription via a secure payment flow. After making updates, the user clicks Save Changes and sees a brief confirmation banner. A Back to Dashboard link returns them to their main workspace.

## Error States and Alternate Paths

If a user enters invalid credentials during sign in or sign up, the form highlights the offending field in red and displays a clear error message such as “Invalid email address” or “Password must be at least eight characters.” During password recovery, submitting an unrecognized email yields a message that the address is not found. When the chat or calendar API calls fail—due to network issues or server errors—the UI shows a dismissible toast banner explaining the failure and offering a Retry button. If the user’s session expires while on any protected page, the app automatically redirects them to the sign-in page with a notice that they need to log in again. Attempts to access restricted routes, such as the admin panel by non-admin users, result in a friendly error page stating “Access Denied” and a link back to the dashboard.

## Conclusion and Overall App Journey

From arrival on the landing page through sign-up and sign-in, the user quickly gains access to a clean dashboard where ongoing or upcoming events appear in an intuitive calendar. The conversational chat interface lets users describe and save schedule items in natural language, while the dashboard’s drag-and-drop and edit modals give direct control. Insightful metrics help the user see patterns in their time usage, and the settings area offers personalization and account management. Error handling and fallback pages ensure the user always understands what to do next. Altogether, this flow guides the user from creating an account to efficiently auditing and optimizing their daily schedule with the AI Schedule Auditor.
